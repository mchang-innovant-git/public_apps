# YYZ ⇄ HKG Fare Tracker (Winter 2026/27)

Daily price tracker for four Toronto–Hong Kong winter trips, in dashboard order: Family + Japan stopover, Family of 4 Direct, Senior couple (Premium Economy), and Solo. Nonstop reference fares (Cathay Pacific / Air Canada) plus, from 2026-08-12, a best-≤1-stop comparison series (any airline, layovers ≤4h, non-CX/AC carriers highlighted) recording price saved and extra travel time.

- `index.html` — the dashboard (GitHub Pages)
- `data/history.json` — full daily price history, one snapshot per day

Data is collected daily from Google Flights and pushed automatically. Prices are CAD, round-trip, per person, taxes included.
